# Дорога

Неспешная езда по заснеженному центру Петербурга прямо в браузере. Вдохновлено [slow roads](https://slowroads.io/), но вместо бесконечной трассы — настоящий город: Невский проспект, канал Грибоедова, Казанский собор, Дом Зингера, светофоры, перекрёстки, трафик и пиксельные прохожие.

Погода и время суток фиксированы: зимняя ночь, густой снег, город в огнях. Картинка нарочно пиксельная.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Управление: **W A S D** / стрелки — ехать, **пробел** — ручник, **Q / E** — поворотники, **мышь** (тянуть) — осмотреться, колесо — ближе/дальше, **V** — взгляд назад, двойной клик — вернуть камеру, **C** — режим камеры, **O** — заказы (необязательная цель: забери в кафе — отвези по адресу), **P** — индикатор нагрузки, **H** — клаксон, **R** — вернуться на дорогу, **M** — мини-карта.

## Как устроено

Всё строится из данных [OpenStreetMap](https://www.openstreetmap.org/) — никаких чужих моделей и панорам. Фонари там, где их нет в OSM, достраиваются процедурно вдоль улиц.

| Файл | Что делает |
|---|---|
| `tools/build-map.mjs` | Сырые данные Overpass → компактный `public/map.json` в локальных метрах |
| `tools/geo.mjs` | Проекция, сборка мультиполигонов, отсечение (покрыто тестами) |
| `data/overrides.json` | Ручные правки к OSM, когда там чего-то не выразить (башня Дома Зингера) |
| `src/ground.js` | Земля: маска дорог/колей/разметки на canvas + фактура в шейдере; лёд, набережные, мосты |
| `src/buildings.js` | Дома по контурам OSM, фасады (окна, карнизы, руст, колоннады) в шейдере, купола |
| `src/car.js` | Машина игрока: плавный разгон, мягкий руль, подвеска с креном и клевком |
| `src/roadgraph.js`, `src/traffic.js` | Граф дорог и NPC-машины по полосам |
| `src/signals.js` | Светофоры с общим по времени циклом (одинаково у всех игроков) |
| `src/peds.js` | Пиксельные пешеходы на тротуарах, ждут зелёного на переходах |
| `src/signs.js` | Вывески: названия заведений из OSM, стиль по категории |
| `src/props.js` | Деревья, фонари, чугунные ограды |
| `src/lights.js` | Карта ночного света: фонари, витрины, отсветы вывесок |
| `src/post.js` | Пиксельный рендер, bloom, дизеринг |
| `src/audio.js` | Процедурный звук без файлов |
| `src/config.js` | Погода, размер пикселя, цикл светофоров |

## Обновить карту

```bash
curl https://overpass.kumi.systems/api/interpreter --data-urlencode \
  'data=[out:json][timeout:90];(nwr(59.9310,30.3180,59.9405,30.3370););out body;>;out skel qt;' \
  -o data/raw/center.osm.json
npm run map
npm test
```

Лучший способ улучшить город — поправить саму OpenStreetMap (этажность, `building:part`, `roof:shape`): это пойдёт на пользу всем.
